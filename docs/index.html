Quick Install via curl (No git clone required)

Downloads the latest GitHub release into ~/.local/share/cosmic-omarchy-clipboard, links omarchy-clipboard, and starts the daemon without overwriting your shortcuts:

curl -fsSL https://github.com/amirlogs/cosmic-omarchy-clipboard/releases/latest/download/install.sh | bash

Want the optional Super + V COSMIC shortcut configured automatically? Pass --with-shortcut:

curl -fsSL https://github.com/amirlogs/cosmic-omarchy-clipboard/releases/latest/download/install.sh | bash -s -- --with-shortcut

Dependencies & OCR (Tesseract) Setup

Install the core Wayland runtime packages plus Tesseract OCR (tesseract + language pack + grim + slurp for screen-region text extraction):

# Fedora 44 / COSMIC
sudo dnf install -y quickshell wl-clipboard wtype jq perl-JSON-PP tesseract tesseract-langpack-eng grim slurp
# Arch Linux
sudo pacman -S --needed quickshell wl-clipboard wtype jq perl tesseract tesseract-data-eng grim slurp
# Ubuntu / Debian
sudo apt install -y wl-clipboard wtype jq libjson-pp-perl tesseract-ocr tesseract-ocr-eng grim slurp

Highlights

Auto-Paste or Copy-Only Defaults to copy-only (Enter); press Shift+Enter to paste, or toggle Auto-paste in Settings.
Inline Editor & Vim Mode Edit entries in place with undo/redo, search, or full Vim motions & text objects.
Local Screen OCR Select any region via grim + slurp and extract text offline with tesseract.
